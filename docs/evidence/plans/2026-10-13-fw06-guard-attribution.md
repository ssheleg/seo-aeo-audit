## Measured current scope

[Inventory](fw06-attribution-inventory.json) is generated by
[the source-aware reader](fw06-attribution-inventory.py), using the owner's
`test/negatives.py:parse_steps` and refusing dirty workflow/parser inputs:

```sh
python3 docs/evidence/plans/fw06-attribution-inventory.py --output <new-snapshot.json>
```

It found **63 helper call sites**: reconciliation step **33** plain `plant` and
**20** named `plantq`, plus **10** plain behavioral `plant` calls. Standalone
negative steps outside those helpers are not included in these counts. The
historical B-33 prose says 41 older calls; the workflow comment says 39. Neither
is the current measured population. Reconcile those claims only with a new
source snapshot, preserving the historical observation.

The structural helper verifies mutation content/mode, then accepts any nonzero
validator exit. Its own comment explains why this is insufficient: the
anchor-liveness guard can reject the mutation even when the intended semantic
guard does nothing. Existing `plantq` requires a diagnostic needle. The behavioral
helper also accepts any checker failure, although it has a different checker and
is not automatically subject to the structural anchor-liveness defect.

A second concrete issue is in the table-width mutation: the regex
`^| B1 | Manual action present |` contains unescaped alternation. A bounded pure
replay against `# unrelated heading\n` with no B1 row still reported one match and
prepended a fabricated row fragment. `n == 1` alone does not prove the intended
row was edited. This is reproduced input behavior, not yet a repaired guard.

## Ordered implementation tasks

1. Claim a separate owner task lease and work on a branch based on accepted B-9
   source. Re-read `.github/workflows/validate.yml`, `test/validate.py`,
   `test/plant_guard.py`, `test/plant_edit.py` and `test/negatives.py`. Preserve all
   trigger policy and `plant_guard.py` shared-family contract; do not fork a shared
   mechanism silently.
2. Freeze a per-call map: description, exact target, mutation selector, intended
   validator/checker diagnostic, checker file and evidence. Use the inventory's
   complete description set as identity; fail on an omitted or duplicate identity.
   Verify each selector against its real target before naming its diagnostic.
   Fix the unescaped table-width selector first and prove it refuses a file with
   no target row.
3. Convert the 33 structural calls to named attribution in coherent guard groups
   (counts/tables, source pointers, coverage vocabulary, provenance, I/O surface).
   Keep the 20 existing named calls and prove their needles refer to their intended
   guard. A nonzero exit caused by syntax failure, import error, unrelated guard or
   anchor liveness must fail the negative test rather than count as success.
4. Add an attribution control: leave the mutation and anchor-liveness guard active,
   disable only the intended semantic guard in an owned scratch tree, and observe
   the old helper's false pass and the named helper's refusal. Restore the semantic
   guard and observe the intended diagnostic. Test absence of the intended needle
   separately from nonzero exit and from a mutation that never landed.
5. Audit the 10 behavioral calls separately. Name their actual assertion or
   failure class, preserve checker selection, and add a nearby unrelated checker
   failure that must not satisfy attribution. Do not claim that converting the
   structural group proves the behavioral group.
6. Add a bounded guard over parsed workflow helper call sites so new anonymous
   calls cannot reappear silently. It must reject a removed expected diagnostic,
   tolerate ordinary whitespace and ignore comments/function definitions. Keep
   one source of call inventory and replay selectors; avoid fixed historical counts
   becoming a second board grammar.
7. Update B-33, the migration receipt, DOCMAP/CONTRIBUTING if a new guard family
   is introduced, and HANDOFF in the same change. Recompute counts from the final
   workflow rather than preserving the historical 39/41 wording as current truth.

failure, correct diagnostic, and disabled intended guard with anchor-liveness
